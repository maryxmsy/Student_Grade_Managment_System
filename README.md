
# 🎓 Student Grade Management System

A Python application to manage student records using CRUD operations and JSON storage.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Calculate Total, Average & Grade
- Automatic JSON Storage
- Duplicate Roll Number Validation
- Marks Validation
- Delete Confirmation

## Technologies

- Python
- JSON
- Pydroid 3
- Git & GitHub
